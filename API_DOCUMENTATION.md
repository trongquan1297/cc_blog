# cc_blog API Documentation

This repository exposes a set of Strapi content-type REST endpoints. This document summarizes the available endpoints (auto-generated) and gives quick curl examples. Adjust schemas in `openapi.yaml` to match your actual content-type fields.

Base URL
- Local: `http://localhost:1337`

Endpoints
- Articles: `GET /api/articles`, `GET /api/articles/{id}`, `POST /api/articles`, `PUT/PATCH /api/articles/{id}`, `DELETE /api/articles/{id}`
- Authors: `GET /api/authors`, `GET /api/authors/{id}`, `POST /api/authors`, `PUT/PATCH /api/authors/{id}`, `DELETE /api/authors/{id}`
- Categories: `GET /api/categories`, `GET /api/categories/{id}`, `POST /api/categories`, `PUT/PATCH /api/categories/{id}`, `DELETE /api/categories/{id}`
- Globals: `GET /api/globals`, `GET /api/globals/{id}`, `POST /api/globals`, `PUT/PATCH /api/globals/{id}`, `DELETE /api/globals/{id}`
- Lead Form Submissions: `GET /api/lead-form-submissions`, `GET /api/lead-form-submissions/{id}`, `POST /api/lead-form-submissions`, `DELETE /api/lead-form-submissions/{id}`
- Product Features: `GET /api/product-features`, `GET /api/product-features/{id}`, `POST /api/product-features`, `PUT/PATCH /api/product-features/{id}`, `DELETE /api/product-features/{id}`
- Pages: `GET /api/pages`, `GET /api/pages/{id}`, `POST /api/pages`, `PUT/PATCH /api/pages/{id}`, `DELETE /api/pages/{id}`

Notes
- These routes were generated by Strapi's `createCoreRouter` in `src/api/*/routes/*.js`.
- The `page` endpoints use a populate middleware (`api::page.page-populate-middleware`) for `find` and `findOne`.
- Authentication & permissions: Strapi typically controls public access via Roles & Permissions. If endpoints return 403, check Strapi admin settings.

Example curl commands

- List articles (public list):
```
curl -X GET "http://localhost:1337/api/articles"
```

- Get an article by ID:
```
curl -X GET "http://localhost:1337/api/articles/1"
```

- Create an article (requires proper auth/permissions):
```
curl -X POST "http://localhost:1337/api/articles" \
  -H "Content-Type: application/json" \
  -d '{"data": {"title": "My Post", "content": "Hello"}}'
```

- Submit a lead form (example):
```
curl -X POST "http://localhost:1337/api/lead-form-submissions" \
  -H "Content-Type: application/json" \
  -d '{"data": {"name":"Jane", "email":"jane@example.com", "message":"Hi"}}'
```

Validating the OpenAPI spec

```
# install
npm install -g @apidevtools/swagger-cli
# validate
swagger-cli validate openapi.yaml
```
